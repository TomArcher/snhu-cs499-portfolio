
# CS 499: Computer Science Capstone

## Tom Archer
Southern New Hampshire University

### ePortfolio

This portfolio documents the enhancement of Event Tracker, an Android application originally developed for CS-360: Mobile Architecture and Programming.

The capstone project includes three enhancement categories:

1. **Software Engineering and Design:** Asynchronous database operations and multithreading.
2. **Algorithms and Data Structures:** Recurring-event scheduling.
3. **Databases:** Image attachments and database schema enhancements.

The portfolio will include the original and enhanced source code, a code review, enhancement narratives, and a professional self-assessment.
